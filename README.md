# Personal Expense Tracker

## About

This project is a command-line based expense tracker built using Python.

I created it to practice working with structured data and file handling. The idea is simple — users can record their daily expenses, categorize them, and view a summary of their spending.

Instead of manually writing expenses somewhere, this program stores them in a structured format and allows basic tracking.

## Features

- Add new expenses
- Categorize expenses (Food, Travel, Bills, etc.)
- Store data using JSON
- View all recorded expenses
- Basic summary of total spending

## Technologies Used

- Python
- JSON
- File handling
- Basic data processing

## How to Run

python expense_tracker.py
